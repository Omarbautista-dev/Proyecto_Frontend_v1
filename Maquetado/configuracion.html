Restauración de datos — no disponible en esta maqueta

Este proyecto no tiene base de datos ni respaldos reales: usa archivos estáticos y almacenamiento local del navegador. No se ofrece una acción de restauración para evitar simular una operación que no existe.

Decisión pendiente: definir si el sistema final debe restaurar un respaldo validado o reiniciar únicamente datos demo.

Para habilitar restauración real se necesita backend con autenticación y permiso administrativo, validación de formato/versión/integridad, vista previa, copia previa del estado, transacción con reversión ante fallos y bitácora de usuario, fecha, origen y resultado.
